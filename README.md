# Tomato

[English](README.md) | [日本語](README.ja.md) | [中文](README.zh.md)

I make voice input tools and bots that watch crypto and stock markets. Most of the code is written with Claude Code.

### Voice

- [voicekey](https://github.com/Tomato-1101/voicekey): voice input for macOS and Windows. Hold a hotkey, speak, and the text is typed into the active window. I use it every day. Site: [voicekey.vercel.app](https://voicekey.vercel.app) (Swift, Python)
- [lecture-ai](https://github.com/Tomato-1101/lecture-ai): records lectures on iPhone, transcribes them, and answers questions about the content. (Swift, TypeScript, Cloudflare Workers)
- [english-live-tutor](https://github.com/Tomato-1101/english-live-tutor): English conversation practice with a realtime voice AI in the browser. (TypeScript, WebRTC)
- [meeting-transcriber](https://github.com/Tomato-1101/meeting-transcriber): turns meeting recordings into a transcript with speaker labels and a summary. (Python, faster-whisper)

### Markets

- [pump-watch](https://github.com/Tomato-1101/pump-watch): watches meme tokens on BSC and sends a Telegram alert when one starts going up. One of its detectors reads swaps directly from BSC logs. Monitoring only, no trading. (Python)
- [scalplab](https://github.com/Tomato-1101/scalplab): records tick data for Japanese stocks and backtests day-trading rules on it. No order placement. (Python)

### Other

- [XAgent](https://github.com/Tomato-1101/XAgent): drafts posts for X. Nothing is posted without my approval. (Python, React)
- [XNewsBot](https://github.com/Tomato-1101/XNewsBot): collects news from X, has Claude pick and summarize it, and sends it on LINE. (Python)
- [menubar-drawer](https://github.com/Tomato-1101/menubar-drawer): hides extra macOS menu bar icons in a drawer. (Swift)
